## Deliberate provenance exceptions

Most documentary workspace prefixes have been replaced with placeholders. Three frozen binding/configuration files remain byte-identical because changing their paths would change the evaluated bindings:

- `workflow/frozen-python-validation/config/mlst-config.json`
- `workflow/frozen-python-validation/config/portable.json`
- `workflow/frozen-rust-evaluation/p4b-bindings.json`

The figure adaptation patch retains an original workspace path as diff context. These paths identify historical locations; they are neither credentials nor portable commands. Historical command ledgers are supplied as `.sh.txt` evidence, not runnable workflows. Only the documented reconstruction/restoration entry points are presented as tested workflows.

Some exact historical files and supplementary tables cite private issue URLs. The table source mapping and scientific summary provide public evidence routes without making those conversations public.

Michael approved one specific additional exception on 22 October 2026: `metadata/provenance/003.artifact` inside the frozen evaluation-package archive contains a dated technical issue brief and agent-written decision summary attributed to Michael. It is preserved solely to retain the original package binding. Its historical software plan is not current user guidance. This is a specific saved technical record, not an export of the issue thread or private discussions generally.

The original student archive, clinical data, meeting transcripts, author correspondence, author markup and private repository history are excluded. References to the student archive in provenance records do not include that archive. The sequence archives contain only explicitly selected, publicly sourced analysed inputs.
